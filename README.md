# ci-cd-sample

CI/CD 파이프라인 구성을 실습하기 위한 샘플 저장소입니다.

## 목적

- GitHub Actions 기반 빌드 / 테스트 / 배포 워크플로 실습
- 브랜치 전략 및 PR 기반 검증 흐름 확인

## 시작하기

```bash
git clone https://github.com/JsonCorp/ci-cd-sample.git
cd ci-cd-sample
```

## 구조

```
.
├── .github/workflows/   # GitHub Actions 워크플로 (예정)
└── README.md
```
