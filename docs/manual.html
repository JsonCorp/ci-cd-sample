할 일을 정확히 다루는 규칙

제목·우선순위·마감일로 할 일을 관리하는 앱입니다. 입력을 거절하는 조건과 목록이 정렬되는 순서가 모두 정해져 있어, 같은 조작이면 항상 같은 결과가 나옵니다. 이 문서는 그 규칙을 전부 적어 둔 것입니다.

목차

  1. 화면 구성
  2. 할 일 추가
  3. 입력 규칙
  4. 우선순위
  5. 마감일
  6. 정렬 순서
  7. 완료와 필터
  8. 진행률
  9. 데이터 저장

화면 구성

화면은 하나뿐입니다. 위에서 아래로 진행률 → 입력 → 필터 → 목록 순입니다.

진행률 0 / 0 완료 (0%) + 진행 막대
입력 제목 · 우선순위 3개 · 추가 · 마감 3개
필터 · 완료 지우기 전체 / 미완료 / 완료
목록 체크박스 · 제목 · 마감 · 우선순위 · 삭제

필터와 완료 지우기가 목록 위에 있는 것은 의도된 배치입니다. 아래에 두면 키보드가 올라왔을 때 가려집니다.

할 일 추가

우선순위와 마감은 고르지 않아도 됩니다. 제목만 있으면 추가됩니다.

  1. 제목을 입력합니다2자 이상 40자 이하. 앞뒤 공백은 자동으로 다듬어집니다.
  2. 우선순위를 고릅니다 (선택)고르지 않으면 ‘보통’입니다.
  3. 마감을 고릅니다 (선택)고르지 않으면 마감 없음입니다.
  4. 추가를 누릅니다목록과 진행률이 함께 갱신됩니다.

추가한 뒤에도 우선순위와 마감 선택은 그대로 남습니다.

제목만 비워지므로, 비슷한 할 일을 연달아 넣을 때 매번 다시 고르지 않아도 됩니다.

입력 규칙

아래 네 조건 중 하나에 걸리면 추가되지 않고, 입력창 밑에 이유가 표시됩니다. 다시 입력을 시작하면 문구는 사라집니다.

조건 기준 표시되는 문구
비어 있음 공백만 입력 할 일을 입력해 주세요.
너무 짧음 다듬은 뒤 2자 미만 2자 이상 입력해 주세요.
너무 김 다듬은 뒤 40자 초과 40자까지 입력할 수 있습니다.
중복 같은 제목이 이미 있음 이미 같은 할 일이 있습니다.

중복은 느슨하게 판정합니다

대소문자와 연속된 공백 차이는 같은 제목으로 봅니다. Buy Milk, buy milk, buy  milk는 모두 같습니다. 이미 완료한 할 일과 제목이 겹쳐도 중복입니다.

목록에 붙는 표시

마감을 정한 할 일은 목록에서 제목 오른쪽에 상태가 붙습니다. 날짜 단위로 비교하므로 같은 날 안의 시각 차이는 결과를 바꾸지 않습니다.

표시 조건
지남마감일이 오늘보다 이전
오늘마감일이 오늘
내일마감일이 내일
예정모레 이후
표시 없음마감을 정하지 않았거나, 이미 완료한 할 일

완료한 할 일에는 마감 표시가 붙지 않습니다.

마감이 지났더라도 그렇습니다. 이미 끝낸 일이 빨갛게 남아 있으면 볼 필요 없는 경고가 쌓입니다. 완료를 되돌리면 표시도 돌아옵니다.

정렬 순서

목록은 직접 끌어 옮길 수 없고, 아래 세 기준이 차례로 적용됩니다.

  1. 미완료가 먼저완료한 항목은 모두 아래로 내려갑니다.
  2. 우선순위가 높은 것이 먼저높음 → 보통 → 낮음.
  3. 먼저 등록한 것이 먼저같은 우선순위 안에서는 추가한 순서를 지킵니다.

마감일은 정렬에 영향을 주지 않습니다. 마감이 임박한 항목을 위로 올리고 싶다면 우선순위를 ‘높음’으로 두십시오.

완료와 필터

완료는 언제든 되돌릴 수 있습니다. 삭제만 되돌릴 수 없습니다.

조작 결과
체크박스 완료/미완료를 전환합니다. 제목에 취소선이 생기고 항목이 아래로 내려가며, 진행률이 다시 계산됩니다.
삭제 그 항목만 지웁니다. 확인을 묻지 않고 즉시 지워지며 되돌릴 수 없습니다.
완료 지우기 완료한 항목을 한 번에 모두 지웁니다. 미완료 항목은 남습니다. 완료가 0건이면 버튼이 비활성 상태입니다.

필터 세 개

탭 보여주는 항목
전체모두
미완료완료하지 않은 것만
완료완료한 것만

필터는 보이는 것만 걸러냅니다. 진행률은 항상 전체를 기준으로 계산되므로 탭을 바꿔도 숫자는 변하지 않습니다. 걸러진 결과가 없으면 표시할 할 일이 없습니다.가 나옵니다.

진행률

화면 맨 위에 완료 개수와 백분율, 진행 막대가 표시됩니다.

상황 표시
할 일이 없을 때0 / 0 완료 (0%)
3건 중 1건 완료1 / 3 완료 (33%)
모두 완료3 / 3 완료 (100%)

백분율은 가장 가까운 정수로 반올림합니다. 3건 중 1건은 33.3…%이므로 33%로 나옵니다. 반올림 때문에 완료가 있는데도 0%가 보일 수 있습니다 — 예를 들어 400건 중 1건이면 0.25%입니다.

데이터 저장

할 일은 기기 안에 저장됩니다. 앱을 완전히 닫았다 켜도 그대로 남습니다.

상황 데이터
앱 종료 후 재실행유지
기기 재부팅유지
앱 업데이트유지
앱 저장공간 삭제 · 앱 삭제모두 사라짐

계정도 서버도 없습니다. 데이터는 이 기기 밖으로 나가지 않으며, 그래서 다른 기기와 동기화되지 않고 백업 기능도 없습니다.
